一元一次方程分层作业

七年级 · 作业设计 · HTML

一、选择与填空

1. 方程 3x + 2 = 11 的解是（ ）。 A. x = 2 B. x = 3 C. x = 4 D. x = 5 2. 解方程 2(x - 3) = 8，得 x = ______。 3. 当 x = ______ 时，代数式 5x - 7 的值是 18。

二、应用与探究

4. 某班购买一批练习本。每本 3 元，加上 6 元运费共支付 66 元。购买了多少本练习本？请列出方程并求解。 5. 小明解方程 4x - 5 = 7 时，写出了 4x = 7 - 5。指出错误，并写出正确的解题过程。

参考答案

1. B。移项得 3x = 9，所以 x = 3。 2. 7。两边同除以 2，得 x - 3 = 4，所以 x = 7。 3. 5。由 5x - 7 = 18 得 5x = 25，所以 x = 5。 4. 设购买 x 本。3x + 6 = 66，解得 x = 20。 5. 移项没有改变符号。应写为 4x = 7 + 5，所以 x = 3。

易错点与评价

关注移项变号和去括号。检查学生能否先找到等量关系，再设未知数。 本页展示 5 题排版节选，不代表已按所选数量完成整份试卷。
