## 页面结构

展示首页 `/welcome` 使用本地地球图片，中央显示教师 AI、简短介绍与立即体验。七项功能说明可直接进入填写页。小屏按顺序排列，不采用可拖动三维场景。

顶部统一安排品牌、首页、工作台、AI 对话、我的作品、使用教程、会员和账号。教学侧栏仅在工作台、工具、结果、对话、作品页出现；教程不在侧栏。

工作区域使用灰白底、轻边框与多色工具标识，保留任务输入及最近作品，不引入 API 消费图表。

工具排序由 `data.js` 的 `tasks` 统一提供：

教学备课 → 练习出题 → 课件制作 → HTML 制作 → AI 数字人 → AI 视频 → 作业批改。

## 实现与边界

- 沿用本地 Vue、Lucide、HTML/CSS/JS，不引入构建或网络运行依赖。
- 独立存储前缀 `teacher-workspace.v2.1-20261012.`，不读取或写入 V2.0 数据。
- 数字人与视频均是静态样稿，不提供不存在的播放或视频下载。
- HTML 样例文件为 `samples/classroom-quiz.html`，包含三道分数题、作答反馈、解析和重新开始。
- 图片素材来源记于 `assets/素材来源.md`。人物照片仅供排版示意，正式项目应使用已取得相应授权的形象资产。
- 没有接入生产服务，所有作品仅保存在本机浏览器。
