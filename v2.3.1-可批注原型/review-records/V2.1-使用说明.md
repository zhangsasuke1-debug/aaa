# V2.1 可批注页面原型

直接双击本目录的 `打开原型.html`，使用 Edge 或 Chrome。无需安装依赖、启动服务器或登录。请保留整个文件夹，不能只移动 HTML。

## 这一轮看什么

1. 首页的地球画面、中央介绍和七项功能入口。
2. “立即体验”进入工作台后的顶部导航、工具侧栏、任务输入和最近作品。
3. 按顺序查看七项工具的填写页、结果页以及返回入口。
4. 新增 HTML 制作、AI 数字人、AI 视频的内容组织是否符合你的想法。

共 27 个页面，可以从评审栏的“页面清单”直接跳转。所有原有页面地址保留，默认入口从 `/home` 调整为 `/welcome`，`/home` 仍是工作台。

## 继续批注

- 顶部“浏览”用于点击跳转；“批注”用于选中页面区域并记录意见。
- 批注面板切换“全部”可查看带入的 4 条旧意见，每条都有本轮调整记录。
- 这 4 条的状态仍是“待你复核”，并未提前标记为用户确认。认可后可点“确认已调整”，也可以继续编辑或新增意见。
- 原始位置、编号、来源版本和修改历史保留；新首页意见当前定位到 `/welcome`。
- HTML 页面预览在批注模式下会暂停内部交互，以便选中整个预览区域；浏览模式可以答题。
- 完成本轮意见后，通过“导出批注 → JSON 备份与交付”导出，供下一轮调整使用。Markdown 只用于阅读。

V2.1 本机存储与 V2.0 分开。不同浏览器、移动文件路径、无痕窗口或清理浏览器数据，都可能影响本机记录；JSON 是可移交的备份。

## 样例边界

- 不连接真实 AI、账号、支付、短信或云存储。
- HTML 制作结果是固定的“认识分数”课堂选择题，不按填写内容生成。下载按钮对应真实的独立 HTML 文件，可在浏览器离线打开。
- 数字人页展示照片、填写的讲稿、选定字幕和画幅。声音选项仅记录意向，没有试听、语音合成、口型驱动或 MP4。
- 视频页是三个地球静态取景的镜头安排。用户参考图片只在浏览器本地预览，不上传，也不会转换成视频。
- 参考图片的文件名会保留，图片内容本身不保存到本机存储；刷新或重新打开保存的样稿后，需重新选择图片。
- 保存作品仅保存本机参数及样稿入口。同一工具修改参数后，可以另外保存一份样稿。
- 图片和运行库均保存在本目录，页面运行不请求外部图片或脚本。

## 版本回溯

根目录的 `版本记录.md` 汇总各版变化。`版本档案/v2.1-20261012/` 是本轮冻结副本，同名 ZIP 便于备份。

`文件指纹清单.json` 与快照内的 `快照清单.json` 记录 SHA-256；“冻结”是维护约定，不是系统写保护。

本 ZIP 包含收到的 4 条原始批注及本轮迁移记录。打开网页之后新增或编辑的批注属于浏览器数据，不会自动写入 ZIP，仍需导出 JSON。

单独解压 V2.1 ZIP 后，本版本页面可独立打开；版本窗口中的 V1、V2.0 跳转需要原工作区的完整档案目录。
